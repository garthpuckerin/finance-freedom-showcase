Finance Freedom · Design System

The soul of MS Money,
in 2026.

Ledger is a desktop-first, data-dense system for the personal-finance app built to succeed Microsoft Money. It keeps what made Money feel like command over your money — the register, the running balance, the reconcile flags, the account tree — and rebuilds it with restrained, modern craft: hairline data tables nested in soft cards, oklch color that re-skins on demand, tabular money typography, and a single quiet accent.

Foundations

Five operating principles

The rules that keep a feature-dense app legible. When a decision is unclear, these break the tie.

01

The number is the hero

Every monetary value is tabular and right-aligned so columns of money scan as a column. Positive and negative carry semantic color, never the surrounding chrome.

02

Sharp tables, soft frames

The ledger itself is crisp and near-edgeless for density. It lives inside a rounded, lightly-shadowed card. Structure is communicated by hairlines and zebra, not boxes around every cell.

03

One quiet accent

A single accent marks the live, the actionable, the focused. Money keeps its own green/red. Color is information — never decoration.

04

Density is a setting, not a default

Built compact-capable from the start. Spacing, row height and type scale move together on one axis so power users can pack the screen without breaking rhythm.

05

Keyboard before mouse

This is a tool, not a feed. Shortcuts, inline editing in the register, and a command palette are first-class — the mouse is the fallback.

Color

A re-skinnable neutral, one accent, stable money

Neutrals are generated in oklch from two variables — a hue and a chroma — so the whole UI shifts temperature without re-picking a single value. Money semantics stay constant so a number means the same thing in every skin.

Signature Pattern

The Ledger

The account register is the soul of the product — the one screen a Money loyalist will recognize instantly. It's a sharp, dense, keyboard-navigable table living inside a soft card: tabular figures, a running balance on every line, payee + category, and a clickable reconcile flag. Zebra striping does the structural work so the grid stays edgeless.

1
Reconcile flag, first column

A single click cycles uncleared → E-cleared → cleared → reconciled. The most-used Money muscle memory, preserved.

2
Tabular money, right-aligned

Payment and Deposit are split columns; decimals line up so the eye can sum a column at a glance.

3
Running balance, always present

The rightmost column never disappears — the defining feature of a register versus a transaction list.

4
Uncategorized is a warning, not an error

Gaps in data are surfaced gently in the warning hue, inviting a fix without alarm.

Signature Pattern

The Cash-Flow Forecast

Money's other defining view: not what you have, but what you will have. A single balance line runs from history straight into the future — solid for what's reconciled, dashed for what's projected from scheduled bills and deposits. A "Today" divider splits the two, event ticks mark each upcoming transaction, and a low-balance threshold turns the line red the moment the projection would dip below your safety floor.

1
One line, two states

Solid = reconciled history. Dashed = projected from scheduled bills, recurring transactions and predicted income. The eye reads continuity, not two charts.

2
The "Today" divider

A quiet vertical rule anchors the present. Everything left already happened; everything right is a forecast you can act on.

3
Safety floor & danger segment

Set a minimum balance; the line turns negative-red wherever the projection crosses below it, with the low point marked. This is the warning Money was famous for.

4
Event ticks

Each upcoming bill (▾) and deposit (▴) is marked on the axis at its date, so a dip always has a cause you can trace.

Data Visualization

Quiet charts, confident categories

Charts default to a single accent or money-semantic hue and only reach for the categorical palette when a series genuinely needs to be told apart. Axes and gridlines are hairlines; the data is the brightest thing on screen.

Voice & Motion

Plain-spoken, fast, never cute

Voice

Speak like a trusted bookkeeper: precise, calm, second-person. Numbers and dates are exact. No exclamation marks on money. "You spent $540 more on dining than last month," not "Whoa, big spender! 🎉"

ClearExactCalm Not hypeNot jargon

Motion

Motion is functional: 120–180ms ease for state, 200–260ms for drawers and the command palette. Numbers may count up on first paint, but the register never animates rows on scroll. If motion doesn't aid comprehension, it doesn't ship.
